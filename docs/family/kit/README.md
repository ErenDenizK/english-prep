# The family kit (to be copied here)

The shared family kit is being written in the portfolio repository (`Portfolio`, at
`docs/family-kit/`). It was not finished when English Prep's family files were prepared
(2026-10-09), so nothing has been copied yet.

When it is final, copy the whole `docs/family-kit/` folder here unchanged (it is reference
material; English Prep does not load any of it at run time). Then check that `../world.json`
follows the kit's `presentation.md` schema; if it does not, adjust `tools/make-world.mjs` and
regenerate with `node tools/make-world.mjs`.

Until then, the vision it implements is `docs/design/family.md` in the portfolio repository,
summarised for English Prep in `../README.md`.
