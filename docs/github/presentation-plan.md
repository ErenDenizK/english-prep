The README is the repository's first product encounter. It should explain the
learner problem, show real use, and give an engineer a short path to the reasoning
and code. It is not a second exhaustive manual or a copy of the About page.

## Narrative and media decisions

1. A self-contained SVG wordmark introduces the product and its academic focus.
2. One sentence identifies the audience: existing English ability, missing
   distinctions. Live app and product-story links appear before documentation.
3. Verified content counts describe the actual corpus, not learning efficacy.
4. Real captures show the read → apply → return loop. A short GIF is optional in
   a disclosure so continuous motion is not the first required reading surface.
5. Feature explanations describe learner outcomes and honest constraints.
6. A small architecture diagram links typed content, native UI and local state.
7. Run commands, validation, research, source preservation and credits finish the
   page. Detailed pre-existing material moves intact to the development guide;
   historical design statements are identified or updated with current links.

No external badge service, tracking image, fake device certification, invented
user metric, runtime requirement or unused contribution template is added.
The SVG is static and contains no scripts, foreign objects or remote resources.
Screenshot progress is isolated demonstration data from the actual app.

## Portability and maintenance

`test` contains the app and technical documents; the historical `main` may carry
only the portfolio README and `docs/github/` assets. All runtime/source/doc links
therefore target the explicit `test` branch, while repository media stays
relative under `docs/github/`. The app and About links target their Pages URLs.
Media is generated by `docs/github/capture.py`; the assets record includes source
routes, viewport, density and capture provenance. Re-run after visual changes.
A GIF has no reliable reduced-motion preference in GitHub Markdown; keep it
behind the explicit disclosure, short, finite per loop, and pair it with a
static scene. Do not add fake play controls to a static image.
